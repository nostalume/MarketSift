# 来源范围与限制

来源可用性取决于本次响应。工具已有适配不保证持续可达、足够新鲜或正文完整；研究需要注明实际观察期、发布时间与取得时间。

| 范围 | 当前入口 | 能说明什么与不能说明什么 |
|---|---|---|
| 行情与合约规则 | OKX 产品、K 线、资金费、成交、OI 与公开归档 | 产品规则与价格；不替代现金股票所有权、股息或账户成交 |
| 宏观序列 | FRED | 取得时版本的数值、单位与频率；不自动提供实时或历史版本信息 |
| 货币与财政 | 美联储、纽约联储、财政部、OFR | 官方发布、操作与财政/融资数据；不是市场买盘的直接测量 |
| 经济与企业 | BEA、BLS、SEC | 原始经济发布和公司披露；最新实际值不等于市场预期 |
| 新闻 | CoinDesk、Cointelegraph、Blockworks、CryptoSlate 等 feed | 发现事件和原文入口；摘要、转载不能重复算独立证据 |
| 分析与作者 | Coin Metrics、Apricitas、Arthur Hayes、Lyn Alden 等公开 feed | 机制解释与竞争观点；不代表全市场共识，部分内容可能付费 |
| 论坛 | Ethereum Research、Uniswap、Reddit、BitcoinMarkets 等公开入口 | 参与者讨论及回复；身份、专业水平与代表性需独立判断 |

完整来源名称与请求参数由 `msharesift.sources` 的实际适配决定。仅列来源不等于本次研究已经覆盖；自定义网页也可能只有导航、登录提示或摘要。

403、429、过旧 feed 和正文截断都属于访问/覆盖限制。仅为会改变判断的缺口寻找免费替代入口，追到关键原文、表格、图表和回复，不无界重试或绕过付费访问。ETF 发行人、公司 IR 和其他公开分析网站可由 Agent 搜索追读，不需要把每个网站先开发成采集器。

政府数据、交易所数据、新闻、作者文章和图表保留各自来源与权利条件。公开可读不等于允许整库再分发；项目不随源码分发抓取正文或个人研究记录。保留原文链接、必要引用和分析依据，MIT 许可不覆盖第三方材料的再授权。
