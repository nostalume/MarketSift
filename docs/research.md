# 使用 Agent 研究

在具有终端、搜索和原文阅读工具的 Agent 中加载 [市场预测与持仓研究 skill](../skills/market-position-research/SKILL.md)，然后提出研究问题与信息截止。项目提供数据工具，搜索和推理来自当前 Agent；仅克隆仓库不会自动启动研究。

例如：分析当前跨资产局势及历史演变，从黄金、能源、美股与加密资产中选择值得新增或退出的敞口，提出明确预测并比较多空与不新增。无需先锁定标的。评估已有账户时，另提供合约代码、持仓、资金占用和风险限制；缺少时只能给出对应范围的市场比较。

围绕能改变主判断的缺口取证：复用已有行情与宏观窗口，先读来源目录，再追读关键正文、表格、图表和反方材料。企业披露、作者推论和 Agent 解释分别保留；不能仅凭新闻数量或过去涨跌排名选标的。

使用 [数据工具](data.md) 获取共享快照。`public-data fetch` 负责获取，`public-data read` 负责离线选读，避免为了换研究角度重复下载。403、429、过旧或截断均保留为覆盖限制，不当作没有相关新闻。具体方法由 skill 统一维护，不在文档再复制一套。

报告保存在用户指定的本地输出目录，保留当时信息截止、关键原文链接、主预测及判错条件；复核时引用旧记录，不覆盖旧预测。期限用于核对命题，不强制持仓到期。行情方向、传导解释、执行条件与真实交易结果分别评价，没有成交记录就不宣称实盘收益。
