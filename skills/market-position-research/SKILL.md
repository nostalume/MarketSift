# 市场预测与持仓研究

使用本项目的公开数据工具与 Agent 搜索、追读能力，为使用者形成有依据、明确可判错的市场预测，并据此比较持仓选择。研究覆盖 OKX 关注产品，日线服务持仓判断，小时线帮助观察传导、反应和执行条件；使用者执行交易。

**预测是核心交付。** 明确选择当前最有依据的未来路径，承担方向、阶段或变化次序的判断，并说明什么事实使预测错误。竞争解释用于挑战和修正主预测，不能以等权罗列上涨、下跌、横盘的可能性代替结论。“等待、不新增持仓”是行动选择，仍需说明市场预测；预测正确也不自动证明当前交易有利。

下文组织相互制约的研究关系，实际工作从当前问题、已有证据和暴露的缺口进入，往返修正。不要把章节变成固定流水线、信息栏目或打分系统。

## 从具体整体形成预测前提

明确研究对象、信息截止与需要作出的判断；接续已有报告中仍成立的事实、未兑现环节与预测。需要账户级建议时取得会改变结论的持仓和风险限制；缺少时完成市场与新增敞口比较，不推定账户状态。

从与问题有关的历史演变重建当前局势：参与者在做什么，依靠何种收入、融资、抵押、制度或政策安排，其行动如何互相支持、限制和改变。历史用于解释当前条件的形成与适用边界，不凭形似行情复制未来。

“整体”的范围由实际联系确定。用跨资产差异、制度转变、现实活动、融资和价格行为发现需要解释的问题；根据问题扩展或收缩研究范围。企业业绩、政策、新闻和 KOL 观点进入研究，应当改变对这些联系的理解。不要随机选企业业绩推出资产方向，也不要将 AI、石油、选举或本次案例预设为未来的主导问题。

区分已观察事实、参与者表述、Agent 解释与未来预测。前提可以先作为有依据的假设；通过会产生不同预测的证据比较来修正它，不把“先彻底弄清主要矛盾”设为开始研究的门槛。

## 在过程内部辨认矛盾与支配关系

寻找使当前过程成立的相互依赖关系，以及这些关系怎样在发展中积累限制自身的条件。把双方落实到实际行动、利益、能力和约束，解释它们怎样共同构成并推动这个过程。观点相反、指标背离或一般利弊只能提出疑问，不能单凭这些标签认定矛盾。

比较有现实依据的竞争解释：各自怎样解释历史到当前的变化、资产表现差异和参与者行为，哪些事实难以解释，接下来会留下什么不同结果。主要矛盾是当前最能组织这些关系、其变化会重排其他重要行动的主导关系；矛盾的主要方面是目前实际支配该过程延续与变化的一侧。说明支配依赖的条件，以及哪种变化会使另一侧取得支配地位。

不要以最宏观、最长期、最轰动或最容易取得资料的题材代替主要矛盾，也不要把所有市场归为一种永久矛盾。长、中、短期的支配关系可以不同，要解释它们如何互为条件、改变彼此，不能仅凭尺度不同宣布互不相关。

在现有证据下作出有排序的工作判断，并针对能改变排序的缺口继续取证。哲学组织问题与重建方式，具体结论由金融机制和事实支持；术语完整不能充当预测依据。

## 通过中介重建预期、行动与反馈

对会改变预测的联系，解释谁改变了什么预期，市场已定价多少，谁有动机且有能力采取什么行动，以及该行动如何影响资产需求、供给与价格。市场预期用可核对的价格、合约、调查或原始表述支持；缺少时保留为假设，不把新闻标题、某位作者或当前利率直接冒充共识。

同时追踪反向作用：价格和波动怎样改变抵押品、保证金、融资能力、风险预算、企业投资和政策反应；这些变化又如何改变后续交易。指出作用的时滞、强弱和换向条件。数量上的支持可能与融资价格上的约束并存，资产上涨也可能同时增强融资能力、提高未来回报兑现要求。

判定标的当前的角色及其购买或出售动机，解释为什么资金会选择它而非其他资产。角色会随参与者和约束改变，不能永久认定 BTC 必为避险资产或某种固定风险代理。跨资产价格比较不等于识别同一账户的资金轮换；现货成交、基金申赎、钱包转移、衍生品持仓各保留其含义。

寻找能区分反馈的观察：同类且超出预期的信息是否仍推动原方向；新增买卖怎样被吸收；预期改善停顿或出现逆向冲击后，已形成的变化能否维持。单次新闻反应、利好不涨或利空不跌只构成线索，需核对已定价内容、抵消因素与后续行为。

## 形成明确的未来预测

报告直接给出“我预测……”所承担的主结论：预计什么对象朝什么方向或阶段发展，哪些变化先发生、哪些随后接续，以及为何这条路径优先于竞争解释。预测需要包含尚未发生、不同结果能区分其对错的内容，不能用已发生的事实、因果套话或“有买盘就涨、没有就跌”交付。

根据命题给出足以核对成败的尺度、时段或事件边界，并说明撤回、推翻和未兑现的含义。方向、路径次序、阶段转换与时间判断按各自承诺核对，不把其中一项命中写成全部正确。没有兑现时不能无限顺延，也不能用“长期总会发生”挽救原预测。

明确表达预测，不能以“可能上涨也可能下跌”“取决于后续情况”结束。条件推演用于说明主路径依靠什么、怎样换向；在当前条件下仍须选出主预测。若有概率估计，它只能补充判断，不代替选择，也不能编造校准或精确数字。

资料不充分时，继续取得能改变选择的证据，并在可得信息下提出最有根据的暂定预测，明确未证实前提。确定性落在所承担的命题与结论上，不能把未知事实、未经识别的因果或收益保证写成确定事实。若关键对象或定义使某项命题无法成立，指出具体断点、完成可支持的预测部分；不用笼统“不确定”退出研究。

把预测与市场已有预期比较。预测一个已被广泛定价的结果，不等于发现交易优势；说明新意在于结果、程度、时点、传导次序还是资产角色。没有差异证据时如实说明，不强行宣称超额收益。

## 在延续与转变中修订判断

趋势延续要解释支撑行为怎样接续，以及该趋势的发展怎样增强或侵蚀自己的条件。反转要定位旧过程的关键关系怎样失效、反向行为怎样取得接续能力。高估值、杠杆或经营恶化本身只说明特定约束与脆弱性，其何时开始支配行为需要额外证据。

价格和行为可以先于基本面改善改变判断。旧方向被反证时及时撤回，即使新原因尚未完全识别；明确尚未识别的环节，不事后补造故事。放弃旧方向与建立新方向分别提供依据，不能要求等待全部宏观事实改善才允许修正，也不能将一次价格变化直接认定为全周期反转。

日线、小时线与长期过程互相提供证据；较快变化能通过融资、持仓和政策反应改变较慢过程。区分长期阶段、当前方向判断、一次执行思路及其失效边界。远处的周线反证不能充当日线转向的唯一启动条件，小时噪声也不能未经传导解释就改写长期判断。

新证据出现时，定位失效的事实、前提、关系、时滞或支配条件；撤去它原有的决定地位，保留仍有效的内容，并据此改变后续预测与持仓比较。旧的方向依据可以转为新方向的风险条件，不因发现某项旧事实仍然存在就坚持原方向。

## 以预测支持人工持仓选择

比较当前可行的独立多头、独立空头、多空组合、持有、退出或不新增，解释哪种选择最符合主预测、当前价格与成本。支持明确建议，不强迫每次成交；资料缺口影响具体建议时，保留对应边界。

长、中、短期按经济过程、传导和价格结构组织；核对预测的时点不规定强制持有期限。持仓延续取决于预期过程是否仍在运行、是否已兑现、是否被反证，以及剩余空间能否覆盖成本。方向正确仍可能入场不利，利润已经兑现也可能削弱继续持有的依据。

按实际产品核对身份、报价与结算币、合约乘数、资金费或交割及适用交易时段，使用已确认的数值与成本计算比较。参考价位不自动成为订单或止损，情景盈亏不冒充期望收益；边界距离不对称时，先触及较近边界不能单独证明方向优势。不给未知账户虚构杠杆、费用或仓位规模，不连接账户或执行交易。

## 围绕分歧轻量取证

复用已经取得且仍适用于当前命题的证据，补取会改变判断的缺口。免费公开数据与 Agent 搜索互补：来源目录帮助发现问题，关键判断追到原文、原表、图表或相关回复；作者与主题筛选服务后续阅读，不预先锁死研究范围。把分析材料当作机制与反驳的线索，按事实依据判断其质量。

核对实际观察期、公开时间、取得时间与修订含义。对齐比较所需的真实时点，不把各来源最后一个值冒充同日数据；历史修订不能冒充当时可知信息。区分未取得、过旧、截断、冲突和真实零值，同源转载不重复计为独立证据，正文含引用或回复时保留观点归属。

直接消费工具返回的已解析值；同次研究共享宏观和文章快照，行情只读取所需窗口并增量补缺。沿用入口解析、清理、缺口、冲突和完整性责任，不添加重复读取、格式校验、全历史加载或额外数据层。403、429 与旧 feed 只针对关键缺口追查免费替代入口，不重试成无界爬取，不以扩源和聚类数量代替预测进展。

按当前任务选择下列项目文档，不要求全部加载：

- [数据工具](../../docs/data.md)：行情、宏观、公开信息的命令、预算和完整性边界。
- [来源限制](../../docs/sources.md)：覆盖范围、观察期和访问边界；历史访问结果不保证本次可用。

使用项目锁文件和已有环境。按当前环境与授权使用 uv 和锁定依赖，不为研究重新搭建环境。查询公开资料与运行已授权工具不延伸为付费、账户操作、发布或部署授权。产品行情复用 OKX；底层公司资料用于研究，不能替代 OKX 产品规则或凭空扩大已适配范围。研究任务不自动授权修改采集器、安装工具或执行交易。

## 交付与回到实践

报告优先呈现明确主预测、标的当前角色和阶段，以及支持选择的关键关系、证据与反证；随后解释持仓比较和复核触发。只保留影响判断的信息，形式随问题调整，不强制填满固定栏目。

需要保存时，在任务输出目录保留预测当时的信息截止、关键依据、承诺的未来结果与判错条件，引用已有证据，不另建强制观点库、记账服务或校验框架。复核分别判断方向、路径、时点、机制与实际交易结果；有人工操作记录时再评价其执行与成本。

新判断带上新的时间和依据，原预测不回写；预测错误就明确承认对应错误。准确说明内容是已检验、暂定还是未能判定，用新解释改变后续预测，避免以补充更多可能性完成复盘。案例中的题材、参数、价格边界和结论不升格为通用规则。
